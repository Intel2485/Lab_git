Реєстрація Команди

Create a Repository

git init [project name] Створити новий локальний репозиторій

git clone my_url Завантажити існуючий репозиторій

Observe your Repository

git status Список нових або змінених файлів

git log Перегляд історії комітів

Working with Branches

git branch Список локальних гілок

git checkout -b [branch] Створити нову гілку та перейти на неї

git merge [branch] Об'єднати гілку з поточною

Make a change

git add [file] Підготувати файл до коміту

git commit -m "message" Зафіксувати зміни

Synchronize

git fetch Отримати зміни з сервера (без злиття)

git pull Завантажити зміни та об'єднати

git push Відправити локальні зміни на сервер
